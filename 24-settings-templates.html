How Templates Work
1
Onboarding creates your Default
Completing the onboarding wizard saves all your brand, paper type, and style choices as the Default Template.
2
New deals use the Default
When you create a deal, the Default Template is applied automatically. You can override it per deal.
3
Edit to update all future deals
Editing the Default Template reopens the onboarding wizard with pre-filled data. Save to apply changes to all future deals.
